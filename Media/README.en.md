# The Way of Light Platform 3D Visual Pack

[English](README.en.md) | [Español](README.md)

Planned images for the **The Way of Light Platform 3D / El Camino de la Luz** project.

This directory is prepared to include the project's visual assets in original and web-optimized versions.

## Planned contents

### original-png/

PNG versions separated from the mockup or original artwork.

- `thewayoflight-logo.png`
- `thewayoflight-cover.png`
- `thewayoflight-banner.png`
- `thewayoflight-thumbnail-01-platforming.png`
- `thewayoflight-thumbnail-02-combat.png`
- `thewayoflight-thumbnail-03-boss-fight.png`
- `thewayoflight-thumbnail-04-light-path.png`

### webp/

The same images converted to `.webp` for web usage.

- `thewayoflight-logo.webp`
- `thewayoflight-cover.webp`
- `thewayoflight-banner.webp`
- `thewayoflight-thumbnail-01-platforming.webp`
- `thewayoflight-thumbnail-02-combat.webp`
- `thewayoflight-thumbnail-03-boss-fight.webp`
- `thewayoflight-thumbnail-04-light-path.webp`

### _source/

Original complete composite image, in PNG and WEBP.

- `thewayoflight-generated-composite.png`
- `thewayoflight-generated-composite.webp`

## Recommended usage

- `thewayoflight-logo.webp` for project identity.
- `thewayoflight-cover.webp` for Open Graph, cover and social sharing.
- `thewayoflight-banner.webp` for the portfolio website.
- Thumbnails for cards, documentation, README files or technical previews.
