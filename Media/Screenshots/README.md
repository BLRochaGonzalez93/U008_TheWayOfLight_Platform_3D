# The Way of Light Platform 3D Visual Pack

[English](README.en.md) | [Español](README.md)

Imágenes previstas para el proyecto **The Way of Light Platform 3D / El Camino de la Luz**.

Este directorio está preparado para incluir los recursos visuales del proyecto en versiones originales y optimizadas para web.

## Uso recomendado

- `thewayoflight-logo.webp` para identidad del proyecto.
- `thewayoflight-cover.webp` para Open Graph, portada y redes.
- `thewayoflight-banner.webp` para la web portfolio.
- Las miniaturas para cards, documentación, README o previews técnicas.
